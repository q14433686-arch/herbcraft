Herbcraft / 百草可食 1.0.0

Minecraft: Java Edition 26.1.2
Loader: Fabric 0.19.3+
Fabric API: 0.151.0+26.1.2
Java: 25

Files:
- herbcraft-1.0.0.jar
  Core module. Required.

- herbcraft-alchemy-1.0.0.jar
  Optional alchemy module. Requires herbcraft.

- herbcraft-cuisine-1.0.0.jar
  Optional cuisine module. Requires herbcraft.

Install:
1. Install Fabric Loader and Fabric API.
2. Put herbcraft-1.0.0.jar into your mods folder.
3. Optionally add herbcraft-alchemy-1.0.0.jar and/or herbcraft-cuisine-1.0.0.jar.

Short description:
Herbcraft makes many vanilla natural items edible and turns them into a slow herbal knowledge system involving taste, rumors, pharmacology, cuisine, and alchemy.
